# MindLoop Design System

Read BRAND.md before making any UI changes. Key rules:

- NEVER use emojis — replace with Lucide React icons only
- Icon library: `lucide-react` exclusively (never mix)
- Icon sizes: 16px, 20px, or 24px
- Colors: #142850 navy (primary), #F59E0B orange (accent), #8B5CF6 purple, #22C55E green, #3B82F6 blue, #EF4444 red
- Background: #F8F6F1 page, #FFFFFF card, #E7E5E4 border
- Owl mascot: hero, empty states, motivation banners ONLY — never in metric cards or stats
- Style target: 70% Linear, 20% Notion, 10% Duolingo
